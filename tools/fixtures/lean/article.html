Reading a stream line by line¶

A ReadableStream hands you chunks, not lines. To read lines, decode the chunks and split them at newlines; see the example below and the TextDecoderStream reference.

Note

The last line of a stream may not end with a newline. Keep the rest of each chunk for the next one.

Example¶

js
async function* lines(stream) {
  const reader = stream.pipeThrough(new TextDecoderStream()).getReader();
  let rest = '';
  for (;;) {
    const { value, done } = await reader.read();
    if (done) break;
    const parts = (rest + value).split('\n');
    rest = parts.pop();
    yield* parts;
  }
  if (rest) yield rest;
}
